notepad pluslus config
========================
Notepad++에서 스타일 설정(예: 테마, 사용자 정의 색상, 폰트 등)을 다른 컴퓨터로 옮기려면 설정 파일을 복사해야 합니다. 방법은 다음과 같습니다:
### 📂 복사해야 할 주요 파일
- **`stylers.xml`** : 사용자 정의 스타일(언어별 색상, 폰트 등)이 저장된 파일
- **`config.xml`** : Notepad++의 일반 환경 설정
- **`themes` 폴더** : 설치된 테마 파일들이 들어 있음
### 📍 파일 위치
기본적으로 Notepad++ 설정 파일은 다음 경로에 있습니다:
- **Windows 10/11**:  
	`C:\Users\<사용자이름>\AppData\Roaming\Notepad++\`
여기서 `AppData` 폴더는 숨겨져 있으니, 탐색기에서 숨김 파일 표시를 켜야 보입니다.

👉 만약 **포터블 버전** Notepad++을 사용한다면, 설정 파일은 프로그램 폴더 안에 저장되므로 해당 폴더 전체를 복사하면 됩니다.

		# 전통적인 Run 레지스트리 경로 매칭용
		$ActualRunPaths = @{
			"HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run" = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run";
			"HKLM:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run" = "HKLM:\Software\Microsoft\Windows\CurrentVersion\Run";
			"HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run32" = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run";
			"HKLM:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run32" = "HKLM:\Software\Microsoft\Windows\CurrentVersion\Run"
		}

		Write-Host "--- '사용 안 함' 상태의 시작 앱을 탐색 및 삭제합니다 ---" -ForegroundColor Cyan

		foreach ($Path in $Paths) {
			if (Test-Path $Path) {
				$SubKeys = Get-ItemProperty -Path $Path
				foreach ($Key in $SubKeys.psobject.Properties) {
					# 기본 속성 제외
					if ($Key.Name -in @("PSPath", "PSParentPath", "PSChildName", "PSDrive", "PSProvider")) { continue }
					
					$Value = $Key.Value
					# 윈도우에서 '사용 안 함'으로 설정된 항목은 바이너리 데이터의 첫 번째 바이트가 02가 아닌 값(보통 03, 01 등)으로 시작합니다.
					if ($Value -and $Value[0] -ne 2) {
						Write-Host "따옴표 탐지: [$($Key.Name)] 항목이 '사용 안 함' 상태입니다. 삭제를 진행합니다." -ForegroundColor Yellow
						
						# 1. StartupApproved 제어 플래그 삭제
						Remove-ItemProperty -Path $Path -Name $Key.Name -ErrorAction SilentlyContinue
						
						# 2. 실제 Run 레지스트리에 있는 원본 키도 삭제
						if ($ActualRunPaths.ContainsKey($Path)) {
							$ActualTarget = $ActualRunPaths[$Path]
							if (Test-Path $ActualTarget) {
								Remove-ItemProperty -Path $ActualTarget -Name $Key.Name -ErrorAction SilentlyContinue
							}
						}
						
						# 3. 만약 시작프로그램 폴더(StartupFolder) 항목이라면?
						if ($Path -like "*StartupFolder*") {
							# 공용 폴더 및 사용자 폴더에서 해당 바로가기(.lnk) 파일 삭제
							$LnkPaths = @(
								"$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\$($Key.Name)",
								"$env:ProgramData\Microsoft\Windows\Start Menu\Programs\Startup\$($Key.Name)"
							)
							foreach ($Lnk in $LnkPaths) {
								if (Test-Path $Lnk) { Remove-Item -Path $Lnk -Force }
							}
						}
					}
				}
			}
		}

		# 3. UWP 앱(스토어 앱) 중 '사용 안 함' 된 항목 정리
		$UwpPath = "HKCU:\Software\Classes\Local Settings\Software\Microsoft\Windows\CurrentVersion\AppModel\SystemSettings\StateRepository\Families"
		if (Test-Path $UwpPath) {
			# UWP 앱의 경우 세부 구조가 복잡하여 사용자 설정 초기화 방식으로 유도하거나, 
			# 위 스크립트 실행 후 컴퓨터를 재부팅하면 대부분의 목록이 갱신되어 사라집니다.
		}

		Write-Host "`n작업이 완료되었습니다. 변경 사항을 반영하려면 '작업 관리자'를 껐다 켜거나 컴퓨터를 재부팅하세요!" -ForegroundColor Green

	}
	
2. 시작 폴더(Startup Folder) 내 바로가기 파일인 경우
	앱이 레지스트리가 아닌 시작 프로그램 폴더에 들어있는 바로가기(.lnk) 파일 형태라면
	아래 명령어로 해당 폴더들을 열어 비활성화된 앱의 바로가기 파일만 직접 삭제해주시면 됩니다.
	{
		Win + R 키를 눌러 실행 창을 엽니다.
		shell:startup 입력 후 엔터 ➔ 사용되지 않는 파일 삭제
		shell:common startup 입력 후 엔터 ➔ 사용되지 않는 파일 삭제 
	}
