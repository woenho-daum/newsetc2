환경설정 명령
=================================
python -m venv .venv
.\.venv\Scripts\Activate.ps1 --> cvenv, alias 환경 만들자

python -m pip install --upgrade pip
{
    ;; cvenv 명령 처리하면 그후에 간단히 하던지 아니면
    pip install -r requirements.txt
    ;; 일일이 설치 하던지
    pip install chrome-devtools-protocol
    pip install websocket-client
    pip install openpyxl pandas xlwings
    pip install pywin32 ahk
}
pip list
pip freeze > requirements.txt

cvenv alias 환경만들기
===========================
{
    $PROFILE -> C:\Users\사용자이름\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1

    if (!(Test-Path $PROFILE)) {
        New-Item -ItemType File -Path $PROFILE -Force | Out-Null
    }
    code $PROFILE
    ----------------
    -> Microsoft.PowerShell_profile.ps1에 추가할 venv 활성화 alias 추가
    -----------------
    function cvenv {
        $project = Join-Path $HOME "Documents\newsetc2"
        Set-Location $project
        & ".\.venv\Scripts\Activate.ps1"
    }
    ----------------
    . $PROFILE  ; 현재 셀에 바로 적용
    cvenv
    pip install -r requirements.txt
    deactivate -> 환경에서 나오기
}

현재 구성은:
{
    Chrome CDP → websocket-client, chrome-devtools-protocol
    Excel 파일 → openpyxl
    Excel 데이터 처리 → pandas
    실행 중인 Excel 제어 → xlwings
    Windows/COM → pywin32
    AHK 연동 → ahk; 현재 PyPI의 최신 1.8.4가 설치되어 있습니다. ahk는 Python에서 AutoHotkey를 제어하는 wrapper이고 AHK v1/v2를 지원합니다.
    numpy 2.5.2 → 수치 계산용 라이브러리
    ----------------------------------------
    pandas 3.0.5 → 데이터 분석/처리용
    openpyxl 3.1.5 → Excel 파일 읽기/쓰기
    xlwings 0.36.17 → Excel과 Python 연동
    Jinja2 3.1.6 → 템플릿 엔진
    websocket-client 1.9.0 → WebSocket 통신 지원
}

{
    deactivate
    python -m pip list
    python -m pip freeze > uninstall.txt
    python -m pip uninstall -r uninstall.txt -y
}
