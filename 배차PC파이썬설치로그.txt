환경설정 명령
=================================
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install chrome-devtools-protocol
pip install websocket-client
pip install openpyxl pandas xlwings
pip install pywin32 ahk
pip list
pip freeze > requirements.txt

현재 구성은:
{
    Chrome CDP → websocket-client, chrome-devtools-protocol
    Excel 파일 → openpyxl
    Excel 데이터 처리 → pandas
    실행 중인 Excel 제어 → xlwings
    Windows/COM → pywin32
    AHK 연동 → ahk; 현재 PyPI의 최신 1.8.4가 설치되어 있습니다. ahk는 Python에서 AutoHotkey를 제어하는 wrapper이고 AHK v1/v2를 지원합니다.
}

{
    if (!(Test-Path $PROFILE)) {
        New-Item -ItemType File -Path $PROFILE -Force | Out-Null
    }
    code $PROFILE

    function cvenv {
        $project = Join-Path $HOME "Documents\newsetc2"
        Set-Location $project
        & ".\.venv\Scripts\Activate.ps1"
    }
}
