와이파이별 고정 아이피
------------------------
1단계: 저장된 와이파이 프로필 이름 정확히 확인하기
==============================
nmcli connection show
(출력 결과 중 NAME 항목에 나오는 이름(예: Company_WiFi, Home_WiFi)을 확인합니다.)

2단계: 회사 Wi-Fi 프로필에 고정 IP 설정하기
===============================
- 암호 없는 경우
nmcli dev wifi connect "회사_와이파이_이름"
nmcli connection modify "회사_와이파이_이름" ipv4.addresses 192.168.0.100/24 ipv4.gateway 192.168.0.1 ipv4.dns "8.8.8.8" ipv4.method manual
- 암호 있는 경우
nmcli dev wifi connect "회사_와이파이_이름" password "xxxx"
nmcli connection modify "회사_와이파이_이름" ipv4.addresses 192.168.0.100/24 ipv4.gateway 192.168.0.1 ipv4.dns "8.8.8.8,1.68.226.1" ipv4.method manual
192.168.0.100/24: 회사에서 사용할 라즈베리 파이의 고정 IP

192.168.0.1: 회사 공유기의 IP (게이트웨이)

3단계: 집 Wi-Fi 프로필에 고정 IP 설정하기
===============================
nmcli connection modify pwh ipv4.addresses 192.168.0.87/24 ipv4.gateway 192.168.0.1 ipv4.dns "8.8.8.8,1.1.1.1" ipv4.method manual
192.168.0.87/24: 집에서 사용할 라즈베리 파이의 고정 IP

4단계: 설정 적용 및 확인
=========================
nmcli connection up "현재_장소의_와이파이_이름"
ip a
wlan0 인터페이스에 각 프로필에서 지정한 고정 IP가 정상적으로 할당되었는지 확인하시면 됩니다. 
이렇게 설정해 두면 회사의 와이파이 범위 내에서는 회사 IP로, 집의 와이파이 범위 내에서는 집 IP로 자동 연결됩니다.
