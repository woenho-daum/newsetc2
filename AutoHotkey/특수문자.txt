1. AutoHotkey 자체에서 특별한 의미를 갖는 문자

| 기호  | 의미    | 예              |
| --- | ----- | -------------- |
| `^` | Ctrl  | `^c` = Ctrl+C  |
| `!` | Alt   | `!f` = Alt+F   |
| `+` | Shift | `+a` = Shift+A |
| `#` | Win   | `#e` = Win+E   |

가. NumpadEnter::

나. :: — Hotkey / Hotstring
    여기서 ::는 이 키가 눌렸을 때 실행할 코드가 시작된다는 의미입니다.
    Hotstring도 ::를 사용합니다.
    ::btw::by the way

다. 문자열에서 특별한 문자
    AHK v2에서는 문자열을 보통 큰따옴표로 감쌉니다.
    name := "홍길동"
    큰따옴표 자체를 문자열에 넣으려면 연속해서 씁니다.
    text := '그가 말했다: "안녕하세요."'
    v2에서는 작은따옴표 문자열도 사용할 수 있어서 이런 경우 편리합니다.

라. ` — 백틱(Backtick)
    AutoHotkey에서 이스케이프 문자 역할을 합니다.
    키보드에서 보통 숫자 1 왼쪽에 있는 문자입니다.
    `n    ; 줄바꿈
    `t    ; 탭
    `r    ; 캐리지 리턴

    특히 AHK에서는 백틱이 중요합니다.
    `"
    → 문자열 안에 " 삽입
    `%
    → %를 문자 그대로 사용

2. RegEx(정규식)에서 특별한 의미를 갖는 문자

SetTitleMatchMode "RegEx"

위의 정규식 선언에 다른 특수문자 모음
===========================================
| 기호      | 의미            | 예                             |
| -------- | ------------- | ----------------------------- |
| `.`     | 임의의 문자 1개     | `a.c` → `abc`, `axc`          |
| `*`     | 앞 문자가 0회 이상   | `ab*c` → `ac`, `abc`, `abbc`  |
| `+`     | 앞 문자가 1회 이상   | `ab+c` → `abc`, `abbc`        |
| `?`     | 앞 문자가 0 또는 1회 | 바로앞의 문자가 있어도,없어도 된다 `colou?r` → `color`, `colour` |
| `^`     | 문자열 시작        | `^abc`                        |
| `$`     | 문자열 끝         | `abc$`                        |
| `[]`    | 문자 집합         | `[0-9]`, `[ABC]`              |
| `[^]`   | 문자 집합 부정      | `[^0-9]`                      |
| `()`    | 그룹            | `(abc)+`                      |
| `\|`    | OR            | `cat\|dog`                    |
| `{n}`   | 정확히 n회        | `a{3}` → `aaa`                |
| `{n,}`  | n회 이상         | `a{2,}`                       |
| `{n,m}` | n~m회          | `a{2,5}`                      |
| `\`     | 특수문자 이스케이프    | `\.` → 실제 `.` 문자              |


| 표현   | 의미            |
| ---- | ------------- |
| `\d` | 숫자 (`0~9`)    |
| `\D` | 숫자가 아닌 문자     |
| `\w` | 영문자, 숫자, `_`  |
| `\W` | `\w`가 아닌 문자   |
| `\s` | 공백(스페이스, 탭 등) |
| `\S` | 공백이 아닌 문자     |
